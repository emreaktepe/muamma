# v2 görselleri

ChatGPT ile üretilen v2 görselleri (prompt paketi: `MUAMMA_gorsel_prompt_paketi_v2.md`) buraya WebP olarak girer.
Dosya adı prompt paketindeki adın aynısıdır (`rol_ortak.webp`, `gorev_kuleler.webp`, `supheli_faustos.webp`, `iz_ayakkabi_0.webp` ...).
Kod `import.meta.glob` ile burada ne varsa onu kullanır; olmayan görselin yerine mevcut görsel ya da çizim gösterilir.
